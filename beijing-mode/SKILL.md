# beijing-mode —— 梁文谷 / 梁文峰 时间分段回复模式

> 用户级 skill，任何 DSH 会话自动可见。作用：让 AI 按**当前北京时间**自动切换回复风格（梁文谷 = 正常回复 / 梁文峰 = 极简回复）。
> 配套状态看板：`E:\Workspace\Project\mode-status`（端口 25565，网页 + /api/status）。
> 修改规则时，需同步更新：本 SKILL.md、`mode-status\server.js`、`mode-status\public\app.js` 三处的分段定义。

## 适用场景

任何对话/回复任务（除非用户明确要求不适用）。

## 规则

回复前**先获取当前北京时间**（用 PowerShell 获取，时区 `China Standard Time`），然后按以下分段选择模式：

### 模式分段（北京时间）

| 时段 | 模式 | 行为 |
|---|---|---|
| 00:00 - 09:00 | 梁文谷模式 | 正常回复 |
| 09:00 - 12:00 | 梁文峰模式 | 极简回复 |
| 12:00 - 14:00 | 梁文谷模式 | 正常回复 |
| 14:00 - 18:00 | 梁文峰模式 | 极简回复 |
| 18:00 - 24:00 | 梁文谷模式 | 正常回复 |

### 梁文峰模式（极简回复）要求

- 能省则省：只保留必要结论，不复述、不扩展、不寒暄
- 回答尽量简短，直接给结论/结果

### 梁文谷模式（正常回复）要求

- 正常详细回复，无特殊限制

### 切换提醒

处于 **08:50 - 09:00** 或 **13:50 - 14:00**（即梁文峰模式开始前 10 分钟）时，回答末尾提醒：

> ⚠️ 快到梁文峰时间了，建议停下。

### 例外与兜底

- 用户明确要求详细回答时，以用户要求为准（不受本模式限制）
- 无法获取北京时间时，默认按 **梁文峰模式** 处理

## 取北京时间的方法（PowerShell）

```powershell
[System.TimeZoneInfo]::ConvertTimeBySystemTimeZoneId((Get-Date), 'China Standard Time')
```
