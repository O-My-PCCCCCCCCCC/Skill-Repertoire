# 模式规则与同步说明

## 模式分段（北京时间）

| 时段 | 模式 | 行为 |
|---|---|---|
| 00:00 - 09:00 | 梁文谷模式 | 正常回复 |
| 09:00 - 12:00 | 梁文峰模式 | 极简回复，能省则省，只保留必要结论 |
| 12:00 - 14:00 | 梁文谷模式 | 正常回复 |
| 14:00 - 18:00 | 梁文峰模式 | 极简回复 |
| 18:00 - 24:00 | 梁文谷模式 | 正常回复 |

## 提醒时段

- 08:50 - 09:00（梁文峰模式开始前 10 分钟）
- 13:50 - 14:00（梁文峰模式开始前 10 分钟）

回答末尾提醒：⚠️ 快到梁文峰时间了，建议停下。

## 例外与兜底

- 用户明确要求详细回答时，以用户要求为准
- 无法获取北京时间时，默认按梁文峰模式处理

## 三处同步（修改规则时必改）

| # | 位置 | 说明 |
|---|---|---|
| 1 | `plugin/lib/client.js` 顶部 `SEGMENTS` / `WARNINGS` | 本插件显示 |
| 2 | `Project\mode-status\server.js` + `public\app.js` | 独立看板（25565 端口） |
| 3 | `~/.dsh/skills/beijing-mode/SKILL.md` | AI 回复行为 |

> 分段用"分钟数"表示：如 09:00 = 540、12:00 = 720、14:00 = 840、18:00 = 1080。
> 时间判断统一用 UTC+8（`Date.now() + 8*3600*1000`），与服务器/浏览器时区无关。

## 颜色映射（DSW 主题变量）

| 状态 | 变量 | 视觉 |
|---|---|---|
| 梁文谷 | `--dsw-alias-state-success-primary` | 绿点 + 绿字 |
| 梁文峰 | `--dsw-alias-brand-primary` | 品牌色点 + 品牌色字 |
| 提醒 | `--dsw-alias-state-warn-primary` | 黄点 + 闪烁动画 |
